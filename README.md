# مشروع صفحة الهبوط البسيطة (Landing Page)

## وصف المشروع
هذا المشروع هو عبارة عن صفحة ويب أساسية تم بناؤها باستخدام لغة **HTML** كجزء من متطلبات مساق *تصميم وإدارة مواقع الويب* في جامعة الأقصى.

## مميزات الكود:
- **منظم وواضح:** تم ترتيب الأوسمة البرمجية لتسهيل القراءة.
- **تضمين التعليقات:** يلتزم المشروع بكتابة `comment` توضيحي قبل وبعد كل قسم (الرأس، القائمة، المحتوى، التذييل).
- **متجاوب:** يدعم العرض بشكل متناسق على الهواتف والأجهزة المختلفة.
